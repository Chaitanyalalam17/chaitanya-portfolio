# FinSight AI

## AI-Powered Financial Intelligence Platform

FinSight AI is an end-to-end financial analytics project
combining data engineering, business intelligence,
machine learning, and explainable AI.

## Planned Features
- Financial data ingestion and processing
- SQL transformations using DuckDB and dbt
- Interactive dashboards using Streamlit
- Credit risk prediction using machine learning
- Explainable AI using SHAP
- AI-powered financial document assistant

## Technologies
Python, SQL, Pandas, NumPy, DuckDB, Streamlit,
Plotly, Scikit-learn, XGBoost, SHAP, FastAPI.
